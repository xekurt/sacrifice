# SACRIFICE

**A web-based bureaucratic dictator simulator exploring the human cost of absolute power.**

## 🔗 Project Links
* **Play the Game (itch.io):** https://rezaei.itch.io/sacrifice

## 🎮 About the Game
*Sacrifice* is a strategy/simulation game built in React. You play as the "Supreme Leader," trapped in an isolated, isometric bunker, managing a fragile and paranoid state. There are no armies to command on a battlefield—only policy dossiers to stamp "Yes" or "No." 

You must balance the demands of four ruthless factions: the Sepah (Military), the Bazaar (Economy), Piety (Religion), and Isolation (Foreign Affairs). Power is a zero-sum game. If any faction's influence drops to 0%, your regime will collapse. If the Military or the Market reaches 100%, they will overthrow you. You cannot win through endless expansion; you can only survive through perpetual crisis, forced to reduce human lives to calculated percentages just to keep the machine running.

## 📚 Academic Context (Course Connection)
This project was developed as an exploration of the course's foundational formula: **Meaning = rep × config**. 
* **Subverting 4X:** Rather than rewarding the eXploration and eXpansion typical of colonial strategy games, *Sacrifice* argues that for an autocrat, true danger comes from within. Growth is punished; stasis is the only goal.
* **Modelling the Immaterial:** The game models the invisible pressures, biases, and paranoia of a totalitarian bureaucracy. 
* **Information Asymmetry:** The UI acts as an unreliable narrator. Players must actively switch their "View" between heavily biased Ministers to understand the state of the nation.
* **The Hidden Cost:** A hidden population consequence system tracks the starvation, emigration, and violence caused by systemic failures, revealing the true human cost only when the reign ends.

## 🛠️ How to Run Locally
This project was bootstrapped with Create React App / Vite. *(Note: edit this based on what you used)*. To run the game locally on your machine:

1. Clone or download the repository.
2. Open your terminal and navigate to the project directory.
3. Install the dependencies by running:
   ```bash
   npm install
   ```
4. Start the development server by running:
   ```bash
   npm start
   ```
   *(Or `npm run dev` if you used Vite).*
5. Open http://localhost:3000 to view it in your browser.

## ♿ Accessibility Features
This game was designed with Universal Design principles in mind, adhering to the belief that everyone has a right to play:
* **Structural/Hardware:** Runs directly in the browser on minimal hardware; no graphics card required.
* **Motor & Cognitive:** Untimed, binary (Yes/No) clicking mechanic removes "play labour" and physical pressure. 3 distinct difficulty modes manage cognitive overload.
* **Visual:** Includes 3 different Colorblind modes.
* **Language:** UI localized into 7 different languages.
